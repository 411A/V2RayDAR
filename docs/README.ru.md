<h1 align="center">V2RayDAR</h1>

<p align="center">
  <em>V2Ray Detection And Reconnaissance — произносится как <code>v2ray</code> + <code>radar</code>.</em><br>
  <img src="https://img.shields.io/badge/engineered_%26_coded_with-human_%2B_multiple_AIs-blueviolet" alt="Спроектировано и написано при помощи нескольких ИИ">
</p>

<p align="center">
  <strong>Запустите один раз на любом постоянно включённом устройстве — старый телефон, ПК, Raspberry Pi или домашний сервер — и V2RayDAR непрерывно находит, проверяет и раздаёт лучшие рабочие конфиги всем устройствам вашей LAN. Он также поднимает стандартный SOCKS5/HTTP-прокси, поэтому каждое устройство вашей LAN получает рабочее V2Ray-соединение — без V2Ray-клиента.</strong>
</p>

<p align="center">
  Быстрый сервис на Rust со встроенным веб-дашбордом, который забирает источники подписок V2Ray / Clash / Mihomo, проверяет их через вашу реальную сеть с помощью <code>sing-box</code>, ранжирует реально работающие конфиги и переиздаёт лучшие на локальном URL подписки, на который могут указывать клиенты v2rayN / v2rayNG / sing-box / Clash Verge / Mihomo. Опциональный терминальный интерфейс (<code>--tui</code>) покрывает несколько дополнительных действий по обслуживанию.
</p>

## 🌐 Веб-панель (по умолчанию)

После запуска приложения откройте http://127.0.0.1:27141 в браузере. ## 🤔 Почему V2RayDAR

- Параллельная загрузка подписок из неограниченного количества источников.
- Поддержка сырых, base64, JSON и YAML форматов — а также ссылок `vmess`, `vless`, `trojan`, `ss`, `ssr`, `hysteria2`, `hy2`, `tuic`.
- **Поддержка конфигураций Clash/Mihomo YAML** — добавьте URL подписки Mihomo, и V2RayDAR автоматически извлечёт все записи прокси.
- **Двунаправленное преобразование форматов** — конвертирует между ссылками V2Ray и записями прокси Clash/Mihomo YAML.
- Проверка каждого кандидата через вашу реальную сеть с `sing-box` (реально загружает тестовый URL через прокси).
- **Двухформатный вывод** — предоставляет рабочие конфигурации как ссылки V2Ray (`/subscription`) **и** полные конфиги Mihomo YAML (`/mihomo.yaml`), так что их может использовать любой клиент.
- Повторная публикация лучших рабочих конфигураций на локальном URL, чтобы любой совместимый клиент видел одну всегда свежую подписку.
- **Постоянный HTTP/SOCKS5-прокси** — держит запущенным процесс `sing-box` с лучшим конфигом, открывая локальный порт прокси для любых приложений. Включите `proxy.enabled` на вкладке Proxy дашборда (или в главном меню TUI) и направьте Telegram, браузеры и любые приложения на `127.0.0.1:27910`.
- **Общий доступ к прокси по LAN** — установите `proxy.discoverable: true`, чтобы привязаться к `0.0.0.0` и добавить правила файрвола, и каждый телефон в вашем Wi-Fi сможет пользоваться прокси. Настройка Telegram в один тап: `https://t.me/socks?server=192.0.2.2&port=27910`.
- **Лист QR-кодов** — генерируйте сканируемые QR-коды для LAN-подписки и Telegram-прокси: на вкладке Share дашборда, кнопками QR у каждого конфига на вкладке Configs или через пункт `QR Codes: Generate & View` главного меню TUI (на десктопе, сохраняется в `v2raydar_data/QRCodes.jpg`). Один скан — и телефон подключён.
- Выживание в ограниченных сетях через ранее проверенные конфигурации в базе данных, мостовую конфигурацию сети или `emergency_config`.
- Необязательный общий доступ по LAN с необязательной защитой токеном, чтобы телефон в вашем кармане мог использовать тот же фид.

## 📦 Быстрая установка

Вставьте строку для вашей ОС в терминал и нажмите Enter — затем ещё раз Enter (ответ по умолчанию «Да»), и установщик завершит всё автоматически с настройками по умолчанию (существующая установка обновится на месте). Ответ «Нет» — пошаговые запросы. Установочный скрипт определяет платформу, загружает последний релиз с `sing-box` и настраивает всё. Портативный режим устанавливает в `Desktop/V2RayDAR` (если есть папка рабочего стола), иначе в `~/V2RayDAR`. Пользовательский режим устанавливает бинарник в `~/.local/bin`.

**Портативный режим** (рекомендуется) — всё в одной папке: просто вставьте команду и нажимайте Enter, пока установка не завершится! Автономная папка (приложенный `sing-box` или существующий `v2raydar_data/` рядом с исполняемым файлом) определяется автоматически, так что работает даже запуск двойным кликом, — `--portable` принудительно включает этот режим в любом месте.

#### <img src="https://cdn.svglogos.dev/logos/linux-tux.svg" alt="Linux" width="20" height="20" align="texttop"> Linux / macOS

```bash
curl -fsSL https://raw.githubusercontent.com/411A/V2RayDAR/main/install.sh | sh
```

#### <img src="https://cdn.svglogos.dev/logos/microsoft-windows-icon.svg" alt="Windows" width="20" height="20" align="texttop"> Windows (PowerShell)

```powershell

```

#### <img src="https://cdn.svglogos.dev/logos/android-icon.svg" alt="Android" width="20" height="20" align="texttop"> Android / Termux

```bash
pkg update -y && apt update && apt full-upgrade -y && pkg install -y curl tar && curl -fsSL https://raw.githubusercontent.com/411A/V2RayDAR/main/install.sh | bash && cd ~/V2RayDAR && ./v2raydar
```

#### User install

Бинарник в `~/.local/bin`, данные в домашней директории:
```bash
# Linux / macOS
curl -fsSL https://raw.githubusercontent.com/411A/V2RayDAR/main/install.sh | sh -s -- --user

# Windows
irm https://raw.githubusercontent.com/411A/V2RayDAR/main/install.ps1 | iex
# Затем выберите вариант 2 при запросе
```

* **Остановить:** `Ctrl + C`
* **Запустить:** `cd ~/V2RayDAR && ./v2raydar`

**Ручная загрузка** — скачайте архив для вашей ОС из [Releases](https://github.com/411A/V2RayDAR/releases/latest) и запустите его — портативные папки определяются автоматически (`--portable` задаёт режим явно).

Установочный скрипт проверяет SHA-256 чек-суммы, определяет установленные копии и предлагает обновление (сохраняя `data.db` и `v2raydar_data/`), по умолчанию не требует sudo.

## 🔰 Быстрый старт

После установки запустите `v2raydar` (в Windows — `v2raydar.exe`). При первом запуске в `data.db` создаются настройки по умолчанию и предварительно выбранные источники подписок. При обновлении существующий `configs.yaml` автоматически переносится в `data.db`.

1. **Дождитесь заполнения.** Приложение загружает источники параллельно, проверяет каждую конфигурацию через вашу сеть и ранжирует рабочие. Эндпоинт доступен с самого начала — клиент может сразу подключиться.
2. **Укажите клиенту** URL подписки:

| Клиент | Эндпоинт |
| --- | --- |
| v2rayN / v2rayNG | `http://127.0.0.1:27141/subscription` (base64) |
| sing-box | `http://127.0.0.1:27141/subscription.txt` (текстовый) |
| Clash Verge / Mihomo | `http://127.0.0.1:27141/mihomo.yaml` |

3. **Пользуйтесь дашбордом** на `http://127.0.0.1:27141` — вкладки Overview, Configs, Subscriptions, Settings, Proxy, Logs и Share. Всё сохраняется мгновенно в базу данных и применяется в живом рантайме.

4. **Меняйте настройки** на вкладке Settings дашборда (или на экране Configurations в TUI с `--tui`) — изменения применяются сразу. Ключевые настройки: `top_n`, `refresh_seconds`, `ping_seconds`, `sharing.enabled`, `probe.mode`. Новые настройки новых версий получают значения по умолчанию автоматически; ваши значения не изменяются.
5. **Выход** по `Ctrl + C`. После выхода эндпоинт останавливается.

### Опциональные элементы управления TUI (`v2raydar --tui`)

| Клавиша | Действие |
| --- | --- |
| `↑` / `↓` или `j` / `k` | Навигация |
| `Enter` | Выбор / переключение / подтверждение |
| `Esc` / `Ctrl+H` | Назад |
| `Space` | Включение/выключение подписки |
| `e` | Редактировать выбранную подписку |
| `Ctrl+R` | Обновление вручную — однократная загрузка, если обновление не выполняется |
| `Ctrl+P` | Ручная перепроверка кэшированных конфигов, если никакой цикл не выполняется |
| `q` | Выход |
| `:` | Режим команд — `:q` выход, `:w` сохранить, `:a` добавить, `:d` удалить, `:n` переименовать, `:u` URL, `:p` приоритет, `:r` обновить, `:ping` проверить |

### Режимы запуска

```bash
v2raydar                # тихий режим — только подсказка браузера, без логов
v2raydar --no-tui       # без TUI — детали и логи
v2raydar --tui          # TUI + локальный эндпоинт подписки
v2raydar --once         # одно обновление, вывод результатов, выход
v2raydar --portable     # данные рядом с исполняемым файлом (в портативных папках определяется автоматически)
v2raydar --uninstall    # удаление данных приложения и правил файрвола
```

Windows-пользователи заменяют `v2raydar` на `v2raydar.exe`. В macOS откройте вложенный `.app` один раз — Gatekeeper запомнит его.

## 🌐 Заметки о ограниченных сетях

- В ограниченных сетях ранее проверенные конфигурации хранятся в базе данных и доступны через `use_cache_only: true`.
- По умолчанию, если некоторые HTTP-URL подписок недоступны, но есть рабочая конфигурация, приложение использует её для повторной попытки загрузки. Если рабочих конфигураций нет, но у вас есть одна рабочая, задайте её как `emergency_config` на вкладке настроек дашборда или на экране конфигурации TUI, чтобы приложение использовало её для повторных попыток загрузки неудавшихся HTTP-подписок.

## 📡 Подключение клиентов к V2RayDAR

- **v2rayN (тот же ПК)** — оставьте `bind: 127.0.0.1:27141` и добавьте `http://127.0.0.1:27141/subscription` как URL подписки.
- **v2rayNG / телефон в той же Wi-Fi** — привяжитесь к LAN-IP ПК (например, `192.0.2.23:27141`), включите `sharing.enabled`, затем используйте `http://192.0.2.23:27141/subscription` на телефоне. Сначала проверьте `/health` с телефона.

Подробное руководство по настройке клиентов, защите токеном и файрволу для каждой ОС см. в [руководстве разработчика](guide.md).

### 📱 Постоянный прокси для трафика приложений

V2RayDAR может запускать постоянный SOCKS5/HTTP прокси рядом с эндпоинтом подписки. Любое приложение на системе — Telegram, браузеры, curl, Python — может маршрутизировать трафик через него без отдельного VPN-клиента.

**Включение на вкладке Proxy дашборда или в строке Proxy в TUI**
(`enabled: true`, порт `27910`, `discoverable: true` = доступ по LAN + правило файрвола).

**Локальное использование (на устройстве с V2RayDAR):**
```bash
# SOCKS5
curl --socks5 127.0.0.1:27910 https://api.ipify.org

# HTTP
curl --proxy http://127.0.0.1:27910 https://api.ipify.org
```

**Использование по LAN (телефон в той же Wi-Fi):**
1. Установите `proxy.discoverable: true` — V2RayDAR добавит правило файрвола и привяжется к `0.0.0.0`.
2. Найдите LAN IP вашего ПК на вкладке Overview дашборда в разделе **Network** (или на панели **Current Configuration** в TUI, или выполните `ipconfig` / `ip addr`). Например `192.0.2.2`.
3. **Telegram:** замените `YOUR_LAN_IP` на ваш реальный LAN IP и откройте этот URL на телефоне:

   ```
   https://t.me/socks?server=YOUR_LAN_IP&port=27910
   ```

   Например, если ваш LAN IP — `192.0.2.2`:
   ```
   https://t.me/socks?server=192.0.2.2&port=27910
   ```

   Или вручную: Telegram → Настройки → Данные и память → Настройки прокси → Добавить прокси:
   - Тип: **SOCKS5** или **HTTP**
    - Хост: `YOUR_LAN_IP` (IP, показанный в дашборде или панели TUI)
   - Порт: `27910`

4. **Глобально на Android:** Настройки → WiFi → долгое нажатие на сеть → Изменить → Дополнительно → Прокси → Вручную → Сервер: `YOUR_LAN_IP`, Порт: `27910`.

Прокси автоматически переключается на следующий лучший конфиг при сбое текущего и выбирает более удачный конфиг при каждом цикле обновления.
