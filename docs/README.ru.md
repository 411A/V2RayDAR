<h1 align="center">V2RayDAR</h1>

<p align="center">
  <em>V2Ray Detection And Reconnaissance — произносится как <code>v2ray</code> + <code>radar</code>.</em><br>
  <a href="https://github.com/411A/V2RayDAR/releases/latest"><img src="https://img.shields.io/github/v/release/411A/V2RayDAR" alt="Последний релиз"></a>

  <a href="https://github.com/411A/V2RayDAR/actions/workflows/rust.yml"><img src="https://github.com/411A/V2RayDAR/actions/workflows/rust.yml/badge.svg" alt="Статус Rust CI"></a>
</p>

<p align="center">
  <strong>Запустите один раз на любом постоянно включённом устройстве — старый телефон, ПК, Raspberry Pi или домашний сервер — и V2RayDAR непрерывно находит, проверяет и раздаёт лучшие рабочие конфиги всем устройствам вашей LAN. Он также поднимает стандартный SOCKS5/HTTP-прокси, поэтому каждое устройство вашей LAN получает рабочее V2Ray-соединение — без V2Ray-клиента.</strong>
</p>

<p align="center">
  Быстрый сервис на Rust со встроенным веб-дашбордом, который забирает источники подписок V2Ray / Clash / Mihomo, проверяет их через вашу реальную сеть с помощью <code>sing-box</code>, ранжирует реально работающие конфиги и переиздаёт лучшие на локальном URL подписки, на который могут указывать клиенты v2rayN / v2rayNG / sing-box / Clash Verge / Mihomo. Опциональный терминальный интерфейс (<code>--tui</code>) покрывает несколько дополнительных действий по обслуживанию.
</p>

## ✨ Возможности

### 🔎 Поиск и проверка

- **Параллельная загрузка** — загрузка подписок из неограниченного количества источников одновременно.
- **Мультиформатность** — сырые, base64, JSON и YAML форматы, а также ссылки `vmess`, `vless`, `trojan`, `ss`, `ssr`, `hysteria2`, `hy2`, `tuic`.
- **Реальная проверка** — проверка каждого кандидата через вашу реальную сеть с `sing-box` (реально загружает тестовый URL через прокси).
- **Умное ранжирование** — реально работающие конфиги ранжируются, самые надёжные — впереди.

### 🔄 Форматы и вывод

- **Ввод Clash/Mihomo** — добавьте URL подписки Mihomo, и V2RayDAR автоматически извлечёт все записи прокси.
- **Двунаправленное преобразование** — конвертирует между ссылками V2Ray и записями прокси Clash/Mihomo YAML.
- **Двухформатный вывод** — предоставляет рабочие конфигурации как ссылки V2Ray (`/subscription`) **и** полные конфиги Mihomo YAML (`/mihomo.yaml`).
- **Один свежий фид** — повторная публикация лучших рабочих конфигураций на локальном URL, чтобы любой совместимый клиент видел одну всегда свежую подписку.

### 🌐 Постоянный прокси

- **Всегда включённый прокси** — держит запущенным процесс `sing-box` с лучшим конфигом, открывая локальный порт прокси для любых приложений, без V2Ray-клиента.
- **Автопереключение** — переход на следующий лучший конфиг при сбое текущего и выбор более удачного конфига при каждом цикле обновления.

### 📱 Доступ по LAN и QR-коды

- **Общий доступ по LAN** — необязательный общий доступ с необязательной защитой токеном, чтобы телефон в вашем кармане мог использовать тот же фид.
- **Прокси по LAN** — привязка к `0.0.0.0` с автоматическими правилами файрвола и настройка Telegram в один тап: `https://t.me/socks?server=192.0.2.2&port=27910`.
- **Лист QR-кодов** — сканируемые QR-коды для LAN-подписки и Telegram-прокси: вкладка Share дашборда, кнопки QR у каждого конфига или пункт `QR Codes: Generate & View` главного меню TUI (на десктопе, сохраняется в `v2raydar_data/QRCodes.jpg`).

### 🔒 Ограниченные сети

- **База проверенных конфигов** — выживание в ограниченных сетях через ранее проверенные конфигурации в базе данных, мостовую конфигурацию сети или `emergency_config`.

## 🖥️ Интерфейсы

### 🌐 Веб-панель (по умолчанию)

Веб-панель — интерфейс по умолчанию, закрывающий повседневное использование с одной страницы браузера: живая статистика Overview, ранжированные Configs с QR-кодом в каждой строке, управление Subscriptions (добавление, редактирование, вкл/выкл, удаление, переупорядочивание перетаскиванием), все настройки на вкладке Settings, вкладка Proxy, общий доступ по LAN, живые Logs и лист QR-кодов для подключения телефонов.

После запуска приложения откройте http://127.0.0.1:27141 в браузере.

## 📦 Установка

Запустите установщик для вашей платформы. Он использует настройки по умолчанию (Enter для принятия) либо задаёт вопросы пошагово при отказе; обновление на месте сохраняет ваши данные.

Что делает установщик: определяет платформу, загружает последний релиз с `sing-box`, проверяет SHA-256 чек-суммы, определяет установленные копии и предлагает обновление (сохраняя `data.db` и `v2raydar_data/`), по умолчанию не требует sudo.

#### <img src="https://cdn.svglogos.dev/logos/linux-tux.svg" alt="Linux" width="20" height="20" align="texttop"> Linux / macOS

```bash
curl -fsSL https://raw.githubusercontent.com/411A/V2RayDAR/main/install.sh | sh
```

#### <img src="https://cdn.svglogos.dev/logos/microsoft-windows-icon.svg" alt="Windows" width="20" height="20" align="texttop"> Windows (PowerShell)

```powershell
irm https://raw.githubusercontent.com/411A/V2RayDAR/main/install.ps1 | iex
```

#### <img src="https://cdn.svglogos.dev/logos/android-icon.svg" alt="Android" width="20" height="20" align="texttop"> Android / Termux

```bash
pkg update -y && apt update && apt full-upgrade -y && pkg install -y curl tar && curl -fsSL https://raw.githubusercontent.com/411A/V2RayDAR/main/install.sh | bash && cd ~/V2RayDAR && ./v2raydar
```

### 👤 Установка для пользователя

Бинарник в `~/.local/bin`, данные в домашней директории:
```bash
# Linux / macOS
curl -fsSL https://raw.githubusercontent.com/411A/V2RayDAR/main/install.sh | sh -s -- --user

# Windows
irm https://raw.githubusercontent.com/411A/V2RayDAR/main/install.ps1 | iex
# Затем выберите вариант 2 при запросе
```

* **Остановить:** `Ctrl + C`
* **Запустить:** `cd ~/V2RayDAR && ./v2raydar`

### 📥 Ручная загрузка

Скачайте архив для вашей ОС из [Releases](https://github.com/411A/V2RayDAR/releases/latest) и запустите его.

**Портативный режим** (рекомендуется) — всё в одной папке. Автономная папка (приложенный `sing-box` или существующий `v2raydar_data/` рядом с исполняемым файлом) определяется автоматически, так что работает даже запуск двойным кликом, — `--portable` принудительно включает этот режим в любом месте. Портативный режим устанавливает в `Desktop/V2RayDAR` (если есть папка рабочего стола), иначе в `~/V2RayDAR`.

## 🚀 Быстрый старт

После установки запустите `v2raydar` (в Windows — `v2raydar.exe`). При первом запуске в `data.db` создаются настройки по умолчанию и предварительно выбранные источники подписок. При обновлении существующий `configs.yaml` автоматически переносится в `data.db`.

1. **Дождитесь заполнения.** Приложение загружает источники параллельно, проверяет каждую конфигурацию через вашу сеть и ранжирует рабочие. Эндпоинт доступен с самого начала — клиент может сразу подключиться.
2. **Укажите клиенту** один из [эндпоинтов подписки](#-эндпоинты-подписки) ниже.
3. **Пользуйтесь дашбордом** на `http://127.0.0.1:27141` — вкладки Overview, Configs, Subscriptions, Settings, Proxy, Logs и Share. Всё сохраняется мгновенно в базу данных и применяется в живом рантайме; настройки, влияющие на обновление, вступают в силу на следующем цикле (дашборд сообщает об этом при сохранении), а изменения списка источников запускают получение сразу.
4. **Меняйте настройки** на вкладке Settings дашборда (или на экране Configurations в TUI с `--tui`) — изменения сохраняются сразу, а настройки, влияющие на обновление, вступают в силу на следующем запланированном цикле или при ручном обновлении. Ключевые настройки: `top_n`, `refresh_seconds`, `ping_seconds`, `sharing.enabled`, `probe.mode`. Новые настройки новых версий получают значения по умолчанию автоматически; ваши значения не изменяются.
5. **Выход** по `Ctrl + C`. После выхода эндпоинт останавливается.

### 📡 Эндпоинты подписки

Три формата вывода — по одному на семейство клиентов:

| Клиент | Эндпоинт |
| --- | --- |
| v2rayN / v2rayNG | `http://127.0.0.1:27141/subscription` (base64) |
| sing-box | `http://127.0.0.1:27141/subscription.txt` (текстовый) |
| Clash Verge / Mihomo | `http://127.0.0.1:27141/mihomo.yaml` |

### ⚙️ Режимы запуска

```bash
v2raydar                # тихий режим — только подсказка браузера, без логов
v2raydar --no-tui       # без TUI — детали и логи
v2raydar --tui          # TUI + локальный эндпоинт подписки
v2raydar --once         # одно обновление, вывод результатов, выход
v2raydar --portable     # данные рядом с исполняемым файлом (в портативных папках определяется автоматически)
v2raydar --uninstall    # удаление данных приложения и правил файрвола
```

Windows-пользователи заменяют `v2raydar` на `v2raydar.exe`. В macOS откройте вложенный `.app` один раз — Gatekeeper запомнит его.

## ⚙️ Конфигурация

<details>
  <summary>👣 <strong>Все настройки и значения по умолчанию</strong></summary>

| Ключ | По умолчанию | Назначение |
| --- | --- | --- |
| `bind` | `127.0.0.1:27141` | Локальный HTTP-адрес для `/subscription`, `/subscription.txt`, `/results` и `/health`. |
| `top_n` | `10` | Количество рабочих конфигураций для публикации клиентам. |
| `refresh_seconds` | `900` | Интервал автообновления (секунды); `0` отключает таймер. |
| `ping_seconds` | `300` | Интервал повторной проверки кэшированных конфигов без повторной загрузки (секунды); `0` отключает. Если кэш подтверждает меньше `top_n`, пинг дополнительно проверяет ранее замеченные конфиги из базы данных. Оба учитываются в Sub Usage. |
| `encoded_subscription` | `true` | `/subscription` возвращает base64 (совместимо с v2rayN / v2rayNG). |
| `prioritize_stability` | `true` | Повторно проверяет сохранённый Top-N предыдущего запуска и сохраняет их впереди, даже если новые конфигурации имеют меньшую задержку. При `false` предпочтение отдаётся любой рабочей конфигурации с низкой задержкой. |
| `return_configs_asap` | `false` | При `true` рабочие конфигурации публикуются в эндпоинт и `Current Found Configs` сразу после обнаружения (макс. `top_n`); ранние конфигурации могут не иметь наилучшей задержки или стабильности. |
| `scan_all_configs` | `false` | При `true` проверяет все загруженные конфигурации, а не останавливается при достаточном количестве. |
| `fetch_timeout_ms` | `30000` | Таймаут загрузки каждого источника. |
| `fetch_concurrency` | `8` | Количество источников, загружаемых параллельно. |
| `max_subscription_bytes` | `33554432` | Максимальный размер каждого источника (32 МиБ). |
| `use_cache_only` | `false` | Пропускает загрузку и берёт ранее проверенные конфигурации из базы данных — полезно в ограниченных сетях. |
| `emergency_config` | `null` | Необязательная рабочая ссылка для использования через `sing-box` в качестве моста при неудачной загрузке HTTP-подписок. |
| `clean_offlines_after_days` | `7` | Дни, после которых недоступные конфигурации удаляются из базы данных. |
| `sharing.enabled` | `false` | Разрешает клиентам LAN доступ к эндпоинтам. |
| `sharing.require_token` | `false` | Запросы LAN требуют `?token=...`. |
| `sharing.token` | `null` | Пусто = отключён, `true` = авто-генерация, строка = указанное значение. |
| `proxy.enabled` | `false` | Запускает постоянный процесс SOCKS5/HTTP прокси через `sing-box`. |
| `proxy.port` | `27910` | Порт смешанного SOCKS5/HTTP прокси. |
| `proxy.discoverable` | `false` | Привязывается к `0.0.0.0` и добавляет правило файрвола для доступа по LAN. |
| `proxy.rotating_proxy` | `true` | `true` переключает прокси на конфигурацию с наименьшим пингом каждый цикл; `false` сохраняет текущую конфигурацию, пока она доступна. |
| `proxy.health_check_url` | `https://cp.cloudflare.com` | URL для проверки работоспособности прокси. |
| `proxy.health_check_interval_seconds` | `60` | Секунды между проверками работоспособности. Автопереключение при сбое. |
| `probe.mode` | `active` | `active` использует `sing-box`; `tcp` только для диагностики. |
| `probe.sing_box_path` | `null` | Необязательный путь к `sing-box`. Оставьте `null` для десктопных сборок `_with_singbox` или сборок Termux со встроенным `sing-box`. |
| `probe.connect_timeout_ms` | `5000` | Таймаут TCP-подключения в диагностическом режиме. |
| `probe.active_timeout_ms` | `30000` | Таймаут HTTP-теста в активном режиме. |
| `probe.startup_timeout_ms` | `5000` | Время ожидания запуска временного прокси. |
| `probe.concurrency` | `16` | Базовый параллелизм активной проверки. |
| `probe.batch_size` | `20` | Начальный размер партии активной проверки. |
| `probe.process_concurrency` | `null` | Количество одновременных процессов `sing-box`; при пустом значении масштабируется автоматически. |
| `probe.test_url` | `https://www.gstatic.com/generate_204` | Тестовый URL, загружаемый через каждого кандидата. |
| `probe.accepted_statuses` | `[204, 200]` | HTTP-коды, считающиеся успешными. |
| `probe.download_url` | `null` | Необязательная цель теста пропускной способности. |
| `probe.download_bytes_limit` | `1048576` | Максимум байт за тест скорости. |
| `geoip_db_path` | `null` | Необязательный путь к файлу `GeoLite2-Country.mmdb` или каталогу country-зон (`zones.txt` или устаревшие `<cc>.zone`). При `null` используется `<data-root>/geoip` (сначала база MaxMind, затем zone; оба обновляются установщиком). Country data: GeoLite2 by MaxMind (CC BY-SA 4.0); fallback zones by ipdeny. |
| `subscriptions` | _(предвыбранные источники)_ | Список источников `{ name, url, enabled, priority }`. Добавьте свои для лучшего покрытия. |

</details>

## 📡 Подключение клиентов

### v2rayN (тот же ПК)

Оставьте `bind: 127.0.0.1:27141` и добавьте `http://127.0.0.1:27141/subscription` как URL подписки.

### v2rayNG / телефон в той же Wi-Fi

Привяжитесь к LAN-IP ПК (например, `192.0.2.23:27141`), включите `sharing.enabled`, затем используйте `http://192.0.2.23:27141/subscription` на телефоне. Сначала проверьте `/health` с телефона.

### sing-box (текстовый формат)

```text
http://127.0.0.1:27141/subscription.txt
```

### Clash Verge / Mihomo (формат YAML)

```text
http://127.0.0.1:27141/mihomo.yaml
```

Импортируйте этот URL напрямую в настройки профиля/подписки вашего Clash-клиента. V2RayDAR генерирует полный конфиг Mihomo с записями прокси, группой `url-test` и сквозным правилом `MATCH`.

Подробное руководство по настройке клиентов, защите токеном и файрволу для каждой ОС см. в [руководстве разработчика](guide.md).

## 🌐 Постоянный прокси

V2RayDAR может запускать постоянный SOCKS5/HTTP прокси рядом с эндпоинтом подписки. Любое приложение на системе — Telegram, браузеры, curl, Python — может маршрутизировать трафик через него без отдельного VPN-клиента.

**Включение на вкладке Proxy дашборда или в строке Proxy в TUI**
(`enabled: true`, порт `27910`, `discoverable: true` = доступ по LAN + правило файрвола).

### Локальное использование (на устройстве с V2RayDAR)

```bash
# SOCKS5
curl --socks5 127.0.0.1:27910 https://api.ipify.org

# HTTP
curl --proxy http://127.0.0.1:27910 https://api.ipify.org
```

### Использование по LAN (телефон в той же Wi-Fi)

1. Установите `proxy.discoverable: true` — V2RayDAR добавит правило файрвола и привяжется к `0.0.0.0`.
2. Найдите LAN IP вашего ПК на вкладке Overview дашборда в разделе **Network** (или на панели **Current Configuration** в TUI, или выполните `ipconfig` / `ip addr`). Например `192.0.2.2`.

### Telegram

Замените `YOUR_LAN_IP` на ваш реальный LAN IP и откройте этот URL на телефоне:

```text
https://t.me/socks?server=YOUR_LAN_IP&port=27910
```

Например, если ваш LAN IP — `192.0.2.2`:
```text
https://t.me/socks?server=192.0.2.2&port=27910
```

Или вручную: Telegram → Настройки → Данные и память → Настройки прокси → Добавить прокси:
- Тип: **SOCKS5** или **HTTP**
- Хост: `YOUR_LAN_IP` (IP, показанный в дашборде или панели TUI)
- Порт: `27910`

### Системный прокси Android

Настройки → WiFi → долгое нажатие на сеть → Изменить → Дополнительно → Прокси → Вручную → Сервер: `YOUR_LAN_IP`, Порт: `27910`.

## 🔒 Ограниченные сети

Три механизма, по порядку:

1. **Ранее проверенные конфиги** — хранятся в базе данных и доступны через `use_cache_only: true`.
2. **Мост внутри сети** — если некоторые HTTP-URL подписок недоступны, но есть рабочая конфигурация, приложение использует её для повторной попытки загрузки. По умолчанию это происходит автоматически; если рабочих конфигураций нет, но у вас есть одна рабочая, задайте её как `emergency_config` (вкладка настроек дашборда или экран конфигурации TUI).
3. **Аварийный конфиг** — ваша собственная известная рабочая ссылка как явный запасной вариант.

Полный порядок повторных попыток и примеры см. в руководстве (раздел Restricted-Network Behavior, на английском).

## ⚠️ Гарантии и безопасность

### Отказ от гарантий

Приложение предоставляется «как есть», без каких-либо гарантий.

### Сторонние конфигурации

V2RayDAR сам по себе не создаёт и не распространяет конфигурации, совместимые с V2Ray. Он сканирует только настроенные вами источники подписок и переиздаёт рабочие конфиги на вашей собственной машине. Вы отвечаете за URL подписок и конфиги, которые сканируете, импортируете и подключаете.

### Предупреждение о безопасности

Владелец V2Ray-сервера, к которому вы подключаетесь, может перехватывать ваш трафик и читать незашифрованные данные. Для использования на той же машине предпочитайте `127.0.0.1:27141`, в общих или ненадёжных LAN включайте `sharing.require_token: true` и никогда не открывайте HTTP-эндпоинт V2RayDAR в публичный интернет. Относитесь к URL подписок и ссылкам как к чувствительным данным.
